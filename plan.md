# Telegram Menu-Based Shop Assistant - Portfolio Showcase

## Goal

Create a portfolio-friendly project showcase for an n8n automation workflow.

The objective is NOT to display raw n8n screenshots or workflow JSON.

Instead, create a visual product showcase that helps recruiters quickly understand:

* The business problem
* The user experience
* The automation workflow
* The technologies used
* The final outcome

This project should feel like a small product case study rather than a technical documentation page.

---

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Static JSON data
* No backend required
